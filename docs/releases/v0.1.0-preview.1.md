# v0.1.0-preview.1 — Source Preview

发布要求：创建为 GitHub Pre-release · 源码评审版

## 下载

- GitHub Release 附带的 `Source code (tar.gz)` / `Source code (zip)`
- 下载前核对 Release 页面记录的 tag 与完整 commit SHA

## 范围

- Python core/sidecar
- React renderer 与合成数据 Fixture
- Rust/Tauri host 与 macOS native helper 源码
- Provider 合同、测试与本地开发包构建工具

## 明确不包含

- `.app`、`.dmg`、`.pkg`
- Developer ID 签名、notarization、stapling
- Apple 支持的终端用户安装体验
- 真实 Provider 账户全矩阵验收声明

## 已知阻断项

- Apple Developer Program 身份不可用，无法完成正式 macOS 分发链。
- 原生资源从校验到执行仍需身份绑定设计闭环；在此之前禁止公开二进制。

## 安全

不要上传真实凭据、Keychain 导出或 Provider 原始响应。漏洞通过 GitHub Security
Advisories 私下报告；本预发布不承诺支持周期。
